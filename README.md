# Kampüs E-Spor Kulübü Web Sitesi

**Repository bağlantısı:** https://github.com/emredemir25015221021/e-spor-klubu

## Projenin amacı
Kampüs E-Spor Kulübü için hazırlanmış üç sayfalık, yapay zekâ destekli bir sitedir. Turnuva ve etkinlik başlıklarında canlı arama yapılabilir. Backend, veritabanı, API ve kullanıcı girişi yoktur; arama tarayıcıda JavaScript ile çalışır.

## Sayfalar
- `index.html` – Ana Sayfa: başlık, tanıtım ve yönlendirme
- `etkinlikler.html` – 6 e-spor etkinliği kartı (başlık, tarih, yer, açıklama) ve arama
- `hakkimizda.html` – Topluluk ve sitenin amacı
- `style.css` – Ortak stil dosyası
- `script.js` – Arama, sayaç, boş sonuç mesajı ve Temizle düğmesi

## Çalıştırma adımları
1. Klasörü indirip açın (veya Codespaces'te açın).
2. `index.html` dosyasını tarayıcıda açın (Codespaces'te Live Server / Open with Live Server).
3. Menüden **Etkinlikler** sayfasına gidip arama kutusuna yazın.

## Diğer belgeler
- `AI_NOTLARI.md` – Prompt'lar ve kod açıklamaları
- `TEST_NOTLARI.md` – Altı test
- `ekran_goruntuleri/` – Normal arama, boş sonuç, mobil görünüm
